# RAG-проект: Консольный помощник по документам

Это учебный проект, реализующий архитектуру **RAG (Retrieval-Augmented Generation)**. 
Программа читает текстовый документ, разбивает его на части, создает векторные представления (эмбеддинги) и сохраняет в локальную базу данных. При задавании вопроса система находит нужные куски текста и передает их в нейросеть **GigaChat** для генерации точного ответа с указанием источника.

## ✨ Основные возможности
*   **Индексация документов (`ingest`)**: Нарезка текста на чанки с перекрытием и сохранение в ChromaDB (защита от дубликатов благодаря `upsert`).
*   **Семантический поиск**: Поиск ответов по смыслу, а не по ключевым словам (устойчивость к опечаткам).
*   **Генерация ответов**: Использование GigaChat API со строгим системным промптом (защита от галлюцинаций).
*   **Демо-режим**: Автоматический прогон тестовых вопросов для быстрой проверки работоспособности.

## 🛠 Технологический стек
*   **Язык:** Python 3.13
*   **LLM (Нейросеть):** GigaChat API (библиотека `gigachat`)
*   **Векторная БД:** `chromadb`
*   **Эмбеддинги:** `sentence-transformers` (модель `all-MiniLM-L6-v2`)
*   **Чтение файлов:** `pdfplumber` (для PDF) и встроенный `open()` (для TXT)
*   **Интерфейс:** `argparse` (CLI)
