# Ручные тест-кейсы (Актуальная версия)

1. Запуск программы: `python main.py` -> должен появиться чат с приглашением "Задайте свой вопрос: ".
2. Вопрос по документу (базовый): Ввести "О чем статья?" -> ИИ выдает осмысленный ответ на основе текста.
3. Вопрос с опечатками: Ввести "Что токое радость?" -> ИИ находит нужный фрагмент, несмотря на ошибки.
4. Вопрос не по теме (ловушка): Ввести "Как приготовить борщ?" -> ИИ отвечает "В моем текущем контексте нет информации...".
5. Проверка ошибки ключа: Удалить/испортить ключ в `.env` -> при вопросе программа выдает "Ошибка: Ключ не найден в файле .env".
6. Проверка кодировки: Открыть `article.txt` -> текст на русском читается (нет "кракозябр").
7. Выход из программы: Ввести "выход" -> программа завершает работу с сообщением "До встречи!".
