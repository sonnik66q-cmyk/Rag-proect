# Ручные тест-кейсы
1. Запуск без аргументов: `python main.py` -> должен вывести справку.
2. Демо-режим: `python main.py demo` -> должен вывести ответ (или мок-ответ).
3. Вопрос по документу: `python main.py ask "О чем статья?"` -> ответ по факту.
4. Вопрос не по теме: `python main.py ask "Как дела?"` -> ответ "В документе нет ответа".
5. Проверка ошибки ключа: Удалить ключ из `.env` -> запустить ask -> ошибка "Ключ не найден".
6. Mock-режим: В коде поставить `mock_mode=True` -> возвращает "[MOCK-ОТВЕТ]".
7. Проверка кодировки: Открыть article.txt -> текст на русском читается.
